# Marca Minha Garagem

A marca combina uma picape prata ilustrada, a forma de uma garagem e uma estrada em cobre. A aplicação usa o arquivo `src/frontend/public/brand/minha-garagem-cobre-v1.png` por meio de `BrandLogo.vue`.

O componente oferece composições para cabeçalho, autenticação, carregamento e rodapé. O nome recebe a cor do tema por máscara alpha, preservando o desenho das letras e o contraste no vidro fumê. Favicons e ícone de tela inicial ficam no diretório público do frontend.

Use a marca com respiro, sem distorcer a proporção, recolorir a ilustração ou aplicar efeitos adicionais de brilho. A paleta de interface está centralizada em `styles/tokens.css`; prata e cobre aproximam marca e visualizador.

A ilustração foi criada para este projeto com assistência de geração de imagem. Créditos dos demais recursos estão em [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md).
